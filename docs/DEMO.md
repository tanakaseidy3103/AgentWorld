# AgentWorld demo (about 3 minutes)

**Video title:** AgentWorld — Collaborative AI Agents Powered by Meta Llama (Hackathon Demo)

**Video description:**
AgentWorld is an open-source visual laboratory for building, testing, and evaluating collaborative AI agents.
Three agents (Ada the Coordinator, Grace the Explorer, and Linus the Builder) use Meta Llama 3.2, running
locally through Ollama, to plan missions, talk to each other, and build in a Unity world. Every model decision
is validated by Unity against the live world before it runs, and every mission can be evaluated with measured
metrics. Code: https://github.com/tanakaseidy3103/AgentWorld

## Before recording

1. Ollama is running and the model is warm: `ollama list` shows `llama3.2`, then run `ollama run llama3.2 "hi"` once.
2. Start from a clean world: `del "%USERPROFILE%\AppData\LocalLow\DefaultCompany\AgentWorld\world.json"`
3. Choose one:
   - **Windows build:** run `AgentWorld.exe` (fullscreen 1920x1080 by default on a 1080p display).
   - **Unity editor:** **AgentWorld → Rebuild World**, open `Main.unity`, set the Game view to 1920x1080, then Play.
4. Mission Control (top right) should read *Meta Llama (Ollama): connected · llama3.2*.
5. Do one full dry run. Missions took about 20-30 seconds on the test laptop.

**Recorder settings (OBS):** Display Capture or Game Capture, 1920x1080 canvas and output, 30 fps, MP4,
CQP 20-23 (or 8,000-12,000 Kbps), microphone on a separate track. Windows Game Bar (Win+Alt+R) also works.

## Expected results (from test runs; the model's exact words will vary)

- The panel shows Ada's decision (places to explore, number of houses and farms), then Grace's reports
  (for example "plaza: 5 free sites"), then a three-to-four line agent conversation.
- Status moves through Planning → Exploring → Selecting → Building → **Succeeded**.
- Llama may choose different sites than the ones named in the mission; that is real model behavior.

## Backup plan if live inference fails

1. Mission Control says *offline*: start Ollama (tray app or `ollama serve`), wait about 15 seconds, and run `ai status` in a terminal.
2. A mission stalls or fails: type `mission stop` in the terminal, wait a few seconds, then run it again.
3. Use the simpler, verified single-agent fallback: `agent builder build a house near the lake`.
4. If live inference still fails, use a take recorded earlier from a real run. **Never edit a video to show a result that didn't happen.**
